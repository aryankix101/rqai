Test Layers, Not More Blends

The next research question is whether each specialized LLM view adds incremental out-of-sample value after the previous layer. This page keeps the planning work separate from the dense evidence pages.

Core rule: do not let every view independently score every stock and then average them. Add one layer at a time; if a layer does not add value, delete it.

Regime Allocator: LLM vs Deterministic Rule

The current evidence says the strategy's incremental edge is more concentrated in stressed environments: high VIX, weak breadth, SPY below its 200-day average, and recent market selloffs. It is weaker in low-volatility grind-up markets.

AllocatorRulePurposeTradable
FixedAlways h10Current clean benchmark for anonymized exponential ranking.Yes
Simple deterministicStressed market: h10; calm market: h20Two-line rule using high VIX, weak breadth, SPY below 200d, and recent selloff evidence.Yes
LLM-selectedLLM chooses one of {5, 10, 20, 40} from market context onlyTest whether the LLM can allocate concentration better than a deterministic rule.Yes
Oracle upper boundChoose the best half-life after observing future returnsNot tradable; measures maximum theoretical value of perfect switching.No
The key metric is not just whether dynamic allocation beats fixed h10. The key metric is how much of the oracle's achievable switching value it captures, and whether it beats a two-line deterministic rule.
Decision rule: if the LLM allocator cannot beat the simple deterministic regime rule, do not use the LLM for regime allocation.

Short-Side Specific Experiments

The short side likely needs a different objective. The anonymized model can improve shorts relative to Trail5, but the short leg may still be weak in absolute expectancy. That means the short book might be a hedge or avoidance mechanism rather than a standalone alpha engine.

Correct short-side question: did the model create a cheaper, safer hedge than random, Trail5, SPY, or sector ETFs? A short sleeve can be useful even if it does not have standalone positive alpha.

Multi-Model Research Should Be Factorial

When testing other LLMs, do not run a simple horse race for highest CAGR. Run a factorial design so we can estimate model effect, masking effect, model x masking interaction, ranking agreement, and complementary errors.

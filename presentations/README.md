# Research Presentations

This folder contains the shareable visual outputs for the mean-reversion LLM
research project. Open the HTML files in a browser after cloning or downloading
the repository.

## Dashboard Suite

Start with [Research Dashboard Hub](research_dashboards/index.html). Its
navigation connects the complete curated suite:

- [Prompt Engineering](research_dashboards/prompt-engineering.html)
- [Autoresearch](research_dashboards/autoresearch.html)
- [Future Experiments](research_dashboards/future-experiments.html)
- [Out-of-Sample Testing](research_dashboards/out-of-sample.html)
- [Latest Campaign](research_dashboards/latest-campaign.html)
- [A/B/C/D Prompt Interaction](research_dashboards/prompt-interaction.html)

The suite also includes the memory postmortem, prompt-cross report, and
consensus report linked from the prompt-engineering dashboard.

V2.5 Balanced Memory Postmortem

Zero-token analysis using memory-ready candidates only. All outcome tests use side-adjusted five-day C2C returns and rebalance-date block bootstraps.

Decision

Do not fund another memory prompt yet. The analog fields moved scores but did not show a stable negative tail.
The strongest absolute memory/outcome rank correlation was only 0.029, while memory strongly changed V2.5 scores. V2.5-added names beat dropped names by -0.011% per date with a 95% CI of -0.219% to 0.200%.
